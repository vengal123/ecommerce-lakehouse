# 🛒 E-commerce Lakehouse Project

Bronze -> Silver -> Gold Architecture using Python + PostgreSQL + Streamlit

## Tech Stack
Python, PostgreSQL, Pandas, Streamlit, Matplotlib

## Files
- `load_bronze.py` - Raw data load
- `load_silver.py` - Data cleaning  
- `load_gold.py` - Business logic
- `app.py` - Live Streamlit Dashboard

## How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
